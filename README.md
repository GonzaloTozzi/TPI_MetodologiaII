# Sistema de Gestión de Solicitudes Académicas — versión base

Prototipo de consola en Python para el TPI de Metodología de Sistemas II.

## Requisitos
- Python 3.9 o superior.
- No requiere librerías externas.

## Uso
```bash
python main.py
```

Los datos se guardan en `solicitudes.json` en el directorio desde el que se ejecuta el programa. El archivo se crea al registrar la primera solicitud.

## Funcionalidades
1. Registrar solicitudes.
2. Listar solicitudes.
3. Cambiar estado.
4. Asignar responsable.
5. Filtrar por estado.
6. Mostrar reporte básico.

## Estructuras de datos
- Solicitud (diccionario)
- Estudiante (diccionario anidado)
- Responsable (diccionario anidado)
